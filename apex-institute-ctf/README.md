## 📜 Storyline
Apex Institute has recently upgraded its student portal. The system administrator claims the new portal is unhackable because they use unbreakable UUIDs for student accounts and have strict access controls on the main profile endpoints. 

Rumor has it that the System Admin's ID card contains a secret system flag. Your mission is to bypass their security measures, find the Admin's ID, and somehow generate their digital ID card. 

**Hint:** Not all APIs are created equal. Sometimes, secondary features are less secure than primary ones.
